# P4 fire-mechanical work reference scopes

Living project, updated continuously.

Paratech's [2025 annual filing](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260320001022), business section 4, lists separate P4 Ph1 154kV and P4 Ph1 Green-dong fire-mechanical contracts. Both rows name Samsung Electronics in the ordering-party field. These are separate disclosed work scopes; they are not treated as aliases or added to another contractor's total.

The 154kV text is retained as part of the project title. It does not establish fire-system circuit voltage, power capacity, equipment count or facility position. The work category remains distinct from [fire-electrical references](electrical_reference_scopes.md).

The selected business-section table supports the existence of these named work packages. It does not specify sprinkler types, pump or valve counts, fire zones, design flow, storage capacity, pipe material, installed dimensions or acceptance results. Filing progress percentages and dates are not campus commissioning dates. No model geometry, installed properties or construction-cost totals are changed. Contract ancestry, overlapping scopes and VAT would require separate checks before combining any monetary records.
